# אפליקציית ציונים לאנדרואיד (לא מחוברת לרשת)

אפליקציה פשוטה שרצה על טלפון Android 4.1.2 (API 16), כמו Galaxy GT-S6310. היא עובדת בלי אינטרנט.
הנתונים נשמרים בטלפון, והחילופים עם המערכת נעשים בקבצים בתיקייה קבועה.

## מה האפליקציה עושה

1. **ייבוא מהמערכת:** שני סוגי קבצים:
   - **רשימת התלמידים (Excel):** קובץ xlsx של המערכת. נקראות העמודות שם פרטי, שם משפחה, ת.ז., כיתה וסטטוס. תלמידים שסטטוסם "עזב" לא מופיעים להזנת ציונים.
   - **ייצוא הציונים (JSON):** קובץ ייצוא מהמודול "ציונים ומיומנויות". נקראים המבחנים, התלמידים והציונים.
2. **הוספה בטלפון:** אפשר להוסיף **מבחן חדש** (מקצוע, שם לא חובה, תאריך) ו**תלמיד חדש** (שם, ת.ז., כיתה) ישירות מהמסכים של הכיתה.
3. **הזנת ציונים:** בוחרים כיתה, בוחרים מבחן, ורושמים ציון (0-100) והערה לכל תלמיד. השמירה נעשית כשיוצאים מהשדה.
4. **ייצוא לקובץ:** כותבת קובץ JSON עם כל הציונים וההערות שנרשמו בטלפון, יחד עם המבחנים והתלמידים שנוספו בטלפון. המערכת מייבאת את הקובץ הזה ישירות.

## איך מזהים תלמיד

התלמיד מזוהה לפי **ת.ז.** (תשע ספרות), כמו במערכת. לכן אפשר לייבא שוב את רשימת התלמידים בלי כפילויות.

## הנחות שנקבעו (אפשר לשנות)

- **החילופים בתיקייה קבועה:** `/sdcard/Mosad/`. מעתיקים לשם את הקבצים מהמערכת (Excel ו-JSON), וכך גם הקובץ שהאפליקציה כותבת.
- **מיזוג בייבוא:** ערך בקובץ מעדכן את הערך בטלפון. ערך ריק בקובץ לא מוחק ציון שנרשם בטלפון.
- **מבחן שנוצר בטלפון וייובא למערכת:** המערכת יוצרת לו מזהה משלה. כשמייבאים חזרה לטלפון את ייצוא הציונים מהמערכת, המבחן מתאחד עם המבחן שנוצר בטלפון ולא נוצר כפול.
- **מדדי קריאה מתקדמים לא נכללים בגרסה הזו.** הם נקראים מה-JSON אבל לא נערכים באפליקציה.
- **אין כניסה עם סיסמה.** הטלפון מכיל נתוני ציונים ות.ז., לכן כדאי לנעול אותו במסך נעילה.

## סדר עבודה מומלץ

1. במערכת: מייצאים את רשימת התלמידים (Excel) ואת ייצוא הציונים (JSON), ומעתיקים לתיקייה `Mosad` בטלפון.
2. באפליקציה: "ייבוא מהמערכת" ובוחרים את קובץ ה-Excel, ואחר כך את קובץ ה-JSON.
3. מזינים ציונים. מוסיפים מבחנים או תלמידים חדשים לפי הצורך.
4. באפליקציה: "ייצוא" (נכתב קובץ `grades-app-...json` בתיקייה).
5. במערכת: מייבאים את קובץ הייצוא. המערכת יוצרת את המבחנים והתלמידים החדשים ורושמת את הציונים.
6. כדי לסנכרן מזהים: מייצאים מהמערכת את ייצוא הציונים ומייבאים אותו לטלפון. (חוזרים על הסבב רק אם רוצים לשמור על אותו זיהוי מבחנים.)

## בניית ה-APK

### אפשרות א': Android Studio במחשב (מומלץ)
1. מתקינים את Android Studio (חינם).
2. File ← Open ← בוחרים את התיקייה `app_android`. הסטודיו מוריד את הכלים לבד.
3. Build ← Build Bundle(s) / APK(s) ← Build APK(s).
4. ה-APK נמצא ב-`app/build/outputs/apk/debug/app-debug.apk`.

### אפשרות ב': GitHub Actions (בלי להתקין כלום במחשב)
1. מעלים את התיקייה `app_android` למאגר GitHub (פרטי או ציבורי).
2. בלשונית Actions מריצים את "Build APK" (או דוחפים שינוי).
3. מורידים את הקובץ `MosadGrades-debug-apk` מסיום הריצה. בתוכו קובץ `app-debug.apk`.

### התקנה על הטלפון
1. מעתיקים את ה-APK לטלפון.
2. בהגדרות ← אבטחה מאפשרים "מקורות לא ידועים".
3. פותחים את הקובץ ומתקינים.

## קבצים בפרויקט

- `app/src/main/java/il/mosad/grades/Db.java` - מסד הנתונים המקומי (SQLite), מזהה תלמיד לפי ת.ז.
- `Io.java` - ייבוא Excel ו-JSON, וייצוא JSON.
- `XlsxReader.java` - קריאת קובץ xlsx (בלי ספריות חיצוניות).
- `Forms.java` - חלונות הוספת תלמיד ומבחן.
- `MainActivity.java` - מסך ראשי: כיתות, ייבוא, ייצוא, תלמיד חדש.
- `ExamListActivity.java` - מבחני כיתה, מבחן חדש, תלמיד חדש.
- `ExamActivity.java` - גיליון הציונים של מבחן.
- `StudentListActivity.java` - כל התלמידים (עם הוספה).
- `StudentActivity.java` - כרטיס תלמיד עם כל הפרטים מרשימת המערכת.
- `app/build.gradle` - הגדרות בנייה (minSdk 16).

## מה לא נבדק עדיין

הקוד נכתב ללא קומפילציה בסביבה שבה נכתב, ולא הורץ על מכשיר. לכן אחרי הבנייה הראשונה צריך לבדוק על המכשיר האמיתי: ייבוא Excel, ייבוא JSON, הוספת מבחן ותלמיד, הזנת ציון, ייצוא, וייבוא חזרה למערכת.
